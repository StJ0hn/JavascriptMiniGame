# Mini-Game em JavaScript e Lógica de Programação

Repositório destinado ao armazenamento das resoluções dos desafios práticos propostos no curso de Lógica de Programação da Alura, integrante do programa Oracle Next Education (ONE).

## Estrutura do Repositório
O projeto foi desenvolvido de forma iterativa, com o código sendo refatorado e expandido a cada novo conceito aprendido.
* /Primeiro desafio ao /Quinto desafio: Diretórios contendo as iterações do desenvolvimento do mini-game, demonstrando a evolução da complexidade estrutural e algorítmica da aplicação.

## Proposta e Conceitos Aplicados
O objetivo central deste repositório é registrar a construção da base lógica em programação. O desenvolvimento progressivo do mini-game exigiu a aplicação e o domínio dos seguintes fundamentos em JavaScript:
* Declaração, atribuição e manipulação de variáveis de estado.
* Controle de fluxo através de estruturas condicionais e laços de repetição.
* Encapsulamento de lógica de negócio em funções reaproveitáveis.
* Manipulação de estruturas de dados básicas (Arrays) e operadores ternários.

## Tecnologias e Ambiente
* JavaScript (Lógica central)
* HTML / CSS (Estruturação e estilização da interface da aplicação)
